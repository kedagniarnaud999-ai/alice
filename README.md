# AliTché — Orientation, Learning & Career Development Platform

> **De l’admission à l’insertion : construis ta voie.**

AliTché is an EdTech and career development platform designed for students, graduates and professionals in Africa, with an initial focus on the Francophone context. It helps users understand their profile, identify realistic directions, develop relevant skills and progressively position themselves for academic and professional opportunities.

## Problem

Many young people struggle to connect their interests, abilities, education and career choices. Academic orientation is often disconnected from employability, while learners and graduates lack a structured digital space to document their profile, build skills and receive actionable guidance.

## Solution

AliTché brings orientation, personal profiling, learning pathways and career positioning into one digital experience. The platform combines structured assessment with personalized recommendations and progressive learning.

## Current MVP

The repository contains a functional web application with a substantial orientation module and the foundations of the learning/career platform.

### Key features

- Psychometric orientation questionnaire with 23 targeted questions
- Six assessment dimensions: cognitive/working profile, motivation, natural talents, interests, constraints and career positioning
- Real-time profile analysis and personalized results
- Career positioning and feasibility insights
- Clear recommended next actions
- Personalized learning pathways and progressive milestones
- User account and profile management
- Dashboard and progress tracking
- Authentication with JWT and Google OAuth
- Email verification and password recovery
- Backend API and PostgreSQL database
- Learning module management

## Product roadmap

- Strengthen the learning module catalogue
- Expand skills validation and competency tracking
- Add opportunity monitoring and personalized opportunity recommendations
- Develop recruiter and university-facing features
- Add richer portfolio/project evidence for employability
- Integrate conversational AI assistance into the user journey

## Technology

**Frontend:** React 18, TypeScript, Vite, Tailwind CSS, React Router, Axios

**Backend:** Node.js, Express, TypeScript, PostgreSQL, Prisma

**Authentication:** JWT, Passport.js, Google OAuth2

**Other:** Nodemailer, Multer, Helmet, CORS and rate limiting
