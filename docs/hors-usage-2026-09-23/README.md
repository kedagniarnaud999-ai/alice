# Documentation hors usage — rangée le 2026-09-23

Ce dossier contient la documentation écrite avant le document de cadrage remis par le fondateur le
2026-09-23. Elle est rangée ici, rien n'a été supprimé.

Elle n'est plus l'autorité. Trois choses y ont été remplacées :

- **la source de vérité** : c'est `docs/CADRAGE-PRODUIT.md`, pas une charte écrite par l'outil ;
- **les numéros** : les documents ci-dessous classent le travail avec des codes à deux lettres
  (`F-04`, `T-021`, `D-07`, `M3`). Ce vocabulaire est abandonné. Le travail se numérote
  `S1.3` dans `docs/BACKLOG.md`, en français ;
- **la méthode de validation** : ces documents découpaient le projet en six étapes de validation bloquantes.
  Cette méthode n'a pas été retenue.

Elle reste lisible pour deux raisons. Les mesures y sont consignées avec leur date, et beaucoup de faits
comptés à la main dans le code ne se reconstituent pas gratuitement. Et l'arbitrage du fondateur peut
changer : si une de ces décisions revient, elle reviendra avec sa trace.

Les fichiers. `00-charter.md` : le contrat de projet, écrit le 2026-09-21, repris le 2026-09-23, jamais
validé — c'est justement ce point de validation que le document du fondateur tranche à sa place. `PRD.md` : la
description du logiciel écran par écran, avec ce qu'affiche chaque écran. `backlog.md` : l'ancien tableau de
référence, remplacé par `docs/BACKLOG.md`. Neuf dossiers sous `modules/`, un par module.

Attention aux liens : ces fichiers en appellent d'autres qui, eux, sont restés dans `docs/`. Un lien cassé
dans un document de ce dossier n'est pas une erreur à corriger, c'est la trace du rangement.
