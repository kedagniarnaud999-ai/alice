# ALITCHÉ — DOCUMENT DE CADRAGE PRODUIT

## 1. IDENTITÉ DU PRODUIT

**Nom :** AliTché
**Signification :** « Ma voie »
**Nature :** Plateforme EdTech / plateforme de développement des parcours académiques et professionnels
**Positionnement :** Orientation, développement des compétences, suivi des parcours et évolution professionnelle
**Cible géographique initiale :** Afrique francophone
**Point de départ :** Orientation dès le post-bac
**Ambition :** Accompagner une personne tout au long de son parcours, de l’orientation à l’évolution professionnelle.

### Promesse

**De l’orientation à l’évolution professionnelle, construis ta voie.**

AliTché ne doit pas être pensé comme une simple application d’orientation, un LMS, un job board ou un logiciel universitaire.

C’est un **écosystème numérique de parcours** permettant à une personne de comprendre son profil, construire son projet, développer ses compétences, suivre son évolution et progressivement valoriser son parcours auprès des établissements et des recruteurs.

---

# 2. VISION PRODUIT

AliTché vise à créer une infrastructure numérique permettant de mieux connecter :

**INDIVIDUS ↔ FORMATION ↔ COMPÉTENCES ↔ EMPLOI ↔ ÉVOLUTION PROFESSIONNELLE**

L'objectif est de réduire les ruptures entre :

* orientation et choix de formation ;
* formation et compétences ;
* compétences et emploi ;
* emploi et développement professionnel.

À terme, AliTché doit pouvoir accompagner une personne pendant plusieurs étapes de sa vie :

**Orientation → Formation → Développement de compétences → Insertion → Évolution professionnelle → Formation continue**

Le produit doit donc être conçu comme un système évolutif, et non comme une succession de fonctionnalités indépendantes.

---

# 3. PROBLÈME CENTRAL

De nombreuses personnes avancent dans leur parcours académique et professionnel sans disposer d'une vision claire de :

* leurs aptitudes ;
* leurs intérêts ;
* leurs motivations ;
* leurs compétences ;
* leurs possibilités d'évolution ;
* leur adéquation avec les formations disponibles ;
* leur adéquation avec les besoins du marché.

Cela peut conduire à :

* des choix de formation peu adaptés ;
* des parcours académiques incohérents ;
* des compétences mal identifiées ou mal valorisées ;
* des difficultés d'insertion ;
* un manque de visibilité pour les recruteurs ;
* un décalage entre les formations proposées et les besoins du marché.

Les établissements et les entreprises disposent également de peu de continuité entre le parcours académique, les compétences acquises et l'évolution professionnelle.

---

# 4. SOLUTION

AliTché centralise progressivement dans un même environnement :

1. l'orientation ;
2. la construction du profil ;
3. le suivi du parcours ;
4. le développement des compétences ;
5. la validation des acquis ;
6. la construction du projet professionnel ;
7. la valorisation du profil ;
8. la connexion avec les opportunités ;
9. le suivi de l'évolution professionnelle.

Le principe fondamental est :

**Profil → Analyse → Orientation → Action → Apprentissage → Validation → Progression → Valorisation**

Chaque nouvelle fonctionnalité doit renforcer cette boucle.

# 7. STRUCTURE FONCTIONNELLE DU PRODUIT

Le produit doit progressivement s'organiser autour de plusieurs grands modules.

## MODULE 1 — ORIENTATION

C'est le point d'entrée stratégique du produit.

L'utilisateur doit pouvoir :

* répondre au questionnaire ;
* analyser son profil ;
* comprendre ses caractéristiques ;
* identifier des domaines cohérents avec son profil ;
* recevoir des recommandations ;
* comprendre pourquoi certaines recommandations sont proposées ;
* conserver les résultats dans son profil.

### Questionnaire actuel

Le questionnaire comporte actuellement 6 dimensions :

1. Profil cognitif
2. Motivations
3. Talents naturels
4. Centres d'intérêt
5. Réalité actuelle
6. Positionnement professionnel

Le questionnaire ne doit pas être traité comme un simple formulaire.

Il constitue la première source de données permettant de construire le profil utilisateur.

---

# MODULE 2 — PROFIL UTILISATEUR

Le profil doit évoluer avec l'utilisateur.

Il ne doit pas être une fiche statique.

Il doit progressivement intégrer :

* informations personnelles ;
* parcours académique ;
* formations ;
* expériences ;
* compétences ;
* intérêts ;
* résultats d'orientation ;
* certifications ;
* réalisations ;
* objectifs ;
* projet professionnel ;
* progression.

Le profil devient progressivement une **identité numérique académique et professionnelle évolutive**.

---

# MODULE 3 — PARCOURS

Le parcours permet à l'utilisateur de visualiser son évolution.

Il doit pouvoir répondre rapidement à :

* Où suis-je ?
* Qu'ai-je déjà accompli ?
* Qu'ai-je validé ?
* Qu'est-ce qu'il me reste à faire ?
* Quelle est ma prochaine étape ?
* Pourquoi cette étape est-elle recommandée ?

Le parcours peut évoluer progressivement :

**Orientation → Formation → Compétences → Expérience → Insertion → Évolution**

---

# MODULE 4 — FORMATION / APPRENTISSAGE

La plateforme doit permettre progressivement d'intégrer des modules de formation.

Un module peut contenir :

* cours ;
* ressources ;
* vidéos ;
* exercices ;
* évaluations ;
* progression ;
* validation ;
* compétences associées.

Chaque formation doit idéalement être liée à une ou plusieurs compétences.

Le système doit progressivement pouvoir montrer :

**Formation suivie → compétence développée → compétence validée**

---

# MODULE 5 — COMPÉTENCES

Les compétences constituent un élément central du produit.

AliTché doit progressivement permettre de :

* identifier les compétences ;
* associer les compétences aux formations ;
* associer les compétences aux expériences ;
* suivre leur niveau ;
* valider certaines compétences ;
* identifier les compétences à développer ;
* recommander des formations ou activités.

À terme, le système peut permettre de comparer :

**Profil actuel ↔ profil cible**

afin d'identifier les écarts de compétences.

---

# MODULE 6 — PROJET PROFESSIONNEL

L'utilisateur doit pouvoir progressivement définir :

* son objectif professionnel ;
* le secteur ciblé ;
* les métiers envisagés ;
* les compétences nécessaires ;
* les formations pertinentes ;
* les expériences à acquérir ;
* les prochaines étapes.

Le projet professionnel doit être dynamique.

Il peut évoluer avec le temps.

---

# MODULE 7 — OPPORTUNITÉS

À terme, AliTché pourra intégrer :

* stages ;
* emplois ;
* formations ;
* programmes ;
* bourses ;
* événements ;
* missions ;
* opportunités professionnelles.

Les recommandations doivent pouvoir être liées au profil de l'utilisateur.

Exemple :

**Profil → compétences → objectif → opportunités pertinentes**

---

# MODULE 8 — PROFIL PROFESSIONNEL / PORTFOLIO

L'utilisateur doit progressivement pouvoir transformer son parcours en une présentation professionnelle.

Le profil peut intégrer :

* formation ;
* expériences ;
* compétences ;
* certifications ;
* projets ;
* réalisations ;
* portfolio ;
* objectifs professionnels.

L'utilisateur garde le contrôle sur ce qui est visible.

---

# MODULE 9 — ÉVALUATIONS ET EXAMENS

Cette fonctionnalité appartient à une phase ultérieure.

Elle pourra permettre :

* examens ;
* tests ;
* évaluations ;
* notation ;
* validation de compétences ;
* suivi des résultats.

Dans le cas des établissements, elle pourra progressivement être reliée au parcours académique.

---

# MODULE 10 — SUIVI DE L'EMPLOYÉ

Fonctionnalité long terme.

AliTché pourra accompagner une personne après son recrutement :

**Recrutement → Intégration → Évaluation → Formation → Développement → Évolution**

Les entreprises pourraient utiliser la plateforme pour :

* suivre les compétences ;
* identifier les besoins de formation ;
* définir des objectifs ;
* suivre les évaluations ;
* accompagner l'évolution professionnelle.

Cette fonctionnalité ne doit pas être développée maintenant sauf décision explicite.

# 8. PARCOURS UTILISATEUR PRINCIPAL

Le parcours principal est presque finalisé.

Il doit être considéré comme une base stable du produit.

### Étape 1 — Découverte

L'utilisateur comprend :

* ce qu'est AliTché ;
* à qui la plateforme s'adresse ;
* ce qu'elle peut lui apporter.

### Étape 2 — Inscription

Création du compte.

### Étape 3 — Profil initial

L'utilisateur fournit les informations nécessaires à la construction de son profil.

### Étape 4 — Orientation

Il réalise le questionnaire.

### Étape 5 — Résultats

AliTché présente :

* son profil ;
* ses caractéristiques ;
* ses centres d'intérêt ;
* ses motivations ;
* ses tendances ;
* des pistes possibles.

### Étape 6 — Recommandations

La plateforme propose des pistes cohérentes avec le profil.

### Étape 7 — Construction du parcours

L'utilisateur commence à définir sa direction.

### Étape 8 — Développement

Il accède aux contenus et activités permettant de développer ses compétences.

### Étape 9 — Validation

Les compétences peuvent progressivement être évaluées et validées.

### Étape 10 — Progression

Le tableau de bord montre l'évolution de l'utilisateur.

### Étape 11 — Valorisation

L'utilisateur construit progressivement son profil professionnel.

### Étape 12 — Opportunités

La plateforme peut progressivement connecter le profil aux formations, stages, emplois ou autres opportunités pertinentes.

### Étape 13 — Évolution professionnelle

À long terme, AliTché continue d'accompagner l'utilisateur après son insertion.

---

# 9. TABLEAU DE BORD

Le dashboard doit être centré sur le parcours.

Il doit éviter de devenir un simple écran rempli de statistiques.

L'utilisateur doit immédiatement comprendre :

* où il en est ;
* ce qu'il a accompli ;
* ce qu'il doit faire ;
* ce qu'il peut faire maintenant ;
* quelles compétences il développe ;
* quelle est sa prochaine étape.

Exemple de logique :

**Votre parcours**
→ Orientation terminée

**Votre progression**
→ 3 compétences développées

**À faire**
→ Compléter votre projet professionnel

**Prochaine étape**
→ Suivre le module X

Le dashboard doit guider l'action.

---

# 10. LOGIQUE DE RECOMMANDATION

Les recommandations doivent être compréhensibles.

AliTché ne doit pas simplement dire :

> "Nous vous recommandons cette formation."

Il doit progressivement pouvoir expliquer :

> "Cette formation vous est recommandée parce qu'elle correspond à votre objectif professionnel et permet de développer les compétences X et Y."

Principe :

**Recommandation = Profil + Objectif + Compétences + Parcours + Contexte**

L'IA peut être utilisée lorsque cela apporte une réelle valeur.

L'IA n'est pas le produit.

# 12. PRINCIPES PRODUIT

## Principe 1 — Le parcours avant les fonctionnalités

Une fonctionnalité n'est pertinente que si elle améliore le parcours utilisateur.

## Principe 2 — L'utilisateur doit comprendre sa progression

À tout moment, il doit pouvoir comprendre où il en est.

## Principe 3 — Chaque donnée doit avoir une utilité

Ne pas demander des informations simplement parce qu'elles pourraient être utiles plus tard.

## Principe 4 — Les recommandations doivent être justifiables

L'utilisateur doit comprendre la logique derrière une recommandation.

## Principe 5 — Construire progressivement

Ne pas développer simultanément toutes les dimensions de la vision.

## Principe 6 — Préserver l'existant

Une nouvelle fonctionnalité ne doit pas casser ou modifier arbitrairement une fonctionnalité existante.

## Principe 7 — Modularité

Les différents espaces doivent pouvoir évoluer sans reconstruire toute la plateforme.

## Principe 8 — Contrôle utilisateur

L'utilisateur doit contrôler les données de son profil et ce qu'il rend visible aux recruteurs ou autres acteurs.

# 21. RÈGLE IMPORTANTE POUR LES MODIFICATIONS

Qoder doit éviter de modifier une fonctionnalité existante simplement pour appliquer une nouvelle idée.

Avant toute modification importante :

1. comprendre la fonctionnalité existante ;
2. identifier ses dépendances ;
3. vérifier son rôle dans le parcours ;
4. mesurer l'impact de la modification ;
5. conserver les comportements utiles ;
6. ne supprimer une fonctionnalité que si cela est explicitement décidé.

# 22. GESTION DU BACKLOG

Toute idée qui ne doit pas être développée immédiatement doit être classée.

### P0 — Maintenant

Indispensable au fonctionnement du produit actuel.

### P1 — Ensuite

Important mais non bloquant.

### P2 — Plus tard

Pertinent pour l'évolution du produit.

### P3 — Vision

Fonctionnalité stratégique à long terme.

### PARKING

Idée intéressante mais dont la pertinence n'est pas encore démontrée.

Une idée ne devient pas automatiquement une fonctionnalité parce qu'elle est intéressante.

À terme, AliTché doit permettre à un utilisateur de dire :

# 29. INSTRUCTION PRINCIPALE À QODER

**Ce document est la référence produit principale d'AliTché.**

Tu dois développer AliTché en respectant la vision, les utilisateurs, le parcours et les priorités définis ici.

Le parcours utilisateur principal est déjà presque atteint.

**Ne recommence pas le produit à zéro.**

**Ne transforme pas le projet en une accumulation de fonctionnalités.**

Avant chaque développement important :

1. analyser l'existant ;
2. identifier la place de la fonctionnalité dans le produit ;
3. vérifier son impact sur le parcours ;
4. vérifier ses dépendances ;
5. proposer la solution la plus simple permettant de répondre au besoin ;
6. préserver les fonctionnalités existantes ;
7. ne pas développer les fonctionnalités long terme prématurément.

Lorsque tu identifies une idée intéressante mais non prioritaire :

**ne la développe pas automatiquement.**

Classe-la dans le backlog avec son niveau de priorité et continue sur la roadmap actuelle.

Lorsque plusieurs solutions techniques sont possibles :

**privilégie celle qui est la plus simple, maintenable, évolutive et cohérente avec l'architecture existante.**

Lorsque l'intention produit n'est pas claire :

**arrête-toi et demande une validation avant de prendre une décision structurante.**

L'objectif n'est pas de produire le plus de fonctionnalités possible.

L'objectif est de construire progressivement **un produit cohérent, utile, simple à utiliser et capable d'évoluer vers la vision complète d'AliTché.**

# 30. RÉSUMÉ EN UNE PHRASE

**AliTché est une plateforme EdTech qui accompagne une personne de l'orientation dès le post-bac à la formation, au développement de compétences, à l'insertion et, à terme, à l'évolution professionnelle, tout en connectant progressivement individus, établissements de formation, consultants et entreprises au sein d'un même écosystème.**
